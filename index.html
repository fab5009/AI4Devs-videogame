Instrucciones

  • Selecciona palabras en línea recta (horizontal, vertical o diagonal).
  • Haz clic y arrastra sobre las letras para marcar una palabra.
  • Las palabras pueden estar en cualquier dirección.
  • Encuentra todas las palabras para ganar.
  • Algunas palabras estarán ocultas en la lista y se revelarán automáticamente cuando las encuentres en la sopa de letras.
  • ¡Atención! Tienes un tiempo limitado para cada nivel. Si el tiempo llega a cero, deberás reiniciar el juego presionando "Nuevo Juego".
