# Desarrollo de un Juego de Búsqueda de Palabras 

## Objetivo: 

Desarrollar un juego web interactivo de búsqueda de palabras, similar al ejemplo proporcionado en la imagen, utilizando HTML, CSS y JavaScript puro. El juego permitirá a los usuarios encontrar palabras ocultas en una cuadrícula de letras, ofreciendo niveles de dificultad crecientes y temas aleatorios.

**1. Descripción General del Juego (Game Overview):** El juego es una aplicación web simple y ligera de búsqueda de palabras. El jugador verá una cuadrícula de letras y una lista de palabras relacionadas con un tema específico. El objetivo es encontrar todas las palabras listadas dentro de la cuadrícula, resaltándolas al hacer clic y arrastrar el cursor. Al encontrar una palabra, esta se marcará como resuelta en la lista. El juego ofrecerá una experiencia progresiva con niveles de dificultad que aumentan a medida que el jugador avanza y presentará temas de palabras de forma aleatoria para cada partida.

 **2. Funcionalidad (Functionality):**Generación de la Cuadrícula:La cuadrícula de letras debe ser generada dinámicamente con un tamaño que variará según el nivel de dificultad.Las palabras a buscar deben ser incrustadas en la cuadrícula en diversas direcciones (horizontales, verticales, diagonales, hacia adelante y hacia atrás), la complejidad de las direcciones aumentará con la dificultad.Los espacios restantes en la cuadrícula deben ser rellenados con letras aleatorias.
 
 **3.Gestión de Temas y Palabras :** Se debe definir una colección de temas, y cada tema contendrá una lista de palabras asociadas.Implementación: Esta colección de temas y sus palabras debe ser definida directamente en el código JavaScript (hardcodeada en un objeto o array de objetos).const temasYPalabras = {
    "FUEGO": ["BRASA", "CALOR", "CENIZA", "CHISPA", "GAS", "HOGUERA", "HUMO", "INCENDIO", "LLAMA", "QUEMA"],
    "ANIMALES": ["PERRO", "GATO", "PAJARO", "PEZ", "LEON", "TIGRE", "ELEFANTE", "MONO"],
    "FRUTAS": ["MANZANA", "PERA", "UVA", "PLATANO", "NARANJA", "FRESA", "KIWI", "PIÑA"],
    // ... agregar más temas y sus palabras
};
Al iniciar cada nueva partida, se seleccionará un tema de forma aleatoria de esta colección.La lista de palabras mostradas al jugador corresponderá al tema seleccionado.
**4.Niveles de Dificultad:**El juego debe incorporar un sistema de niveles que aumente la dificultad a medida que el jugador complete partidas.Los parámetros que ajustarán la dificultad incluirán (pero no se limitarán a):Tamaño de la cuadrícula: Más grande para niveles más difíciles.Número de palabras a encontrar: Más palabras para niveles más difíciles.Longitud promedio de las palabras: Palabras más largas en niveles más difíciles.Direcciones de las palabras: Incluir diagonales y palabras hacia atrás en niveles de dificultad media y alta.El juego debe llevar un registro del nivel actual del jugador.Interacción del Jugador:El jugador podrá seleccionar letras haciendo clic y arrastrando el cursor para formar una palabra.Al soltar el clic, el juego debe verificar si las letras seleccionadas forman una de las palabras a buscar del tema actual.Si la palabra es correcta:Las letras de la palabra encontrada deben resaltarse visualmente en la cuadrícula (por ejemplo, con un color de fondo diferente).La palabra debe marcarse como "resuelta" en la lista de palabras (por ejemplo, tachándola o cambiando su color).Si la palabra no es correcta, la selección debe borrarse y volver al estado inicial.Debe haber un contador que muestre cuántas palabras han sido encontradas o cuántas quedan por encontrar.Estado del Juego:Cuando todas las palabras sean encontradas, el juego debe mostrar un mensaje de felicitación y avanzar al siguiente nivel de dificultad (o reiniciar si es el nivel máximo).Posibilidad de reiniciar el juego en cualquier momento.
**5. Estilo (Styling):Diseño Responsivo:** El juego debe ser adaptable a diferentes tamaños de pantalla, aunque el enfoque principal será una vista de escritorio/tablet.Diseño Visual Atractivo:La cuadrícula de letras debe tener un diseño claro y legible. Cada celda de letra debe estar bien definida.Las palabras a buscar deben mostrarse en una lista separada, con un estilo que indique claramente las palabras pendientes y las palabras encontradas.Se debe implementar un efecto de resaltado visual claro cuando el jugador arrastra el cursor para seleccionar letras y cuando una palabra es encontrada.Uso de colores y tipografías que mejoren la experiencia del usuario, inspirándose en el mock-up proporcionado ().Elementos de la Interfaz:Título del juego y del tema actual (ej. "TEMA: ANIMALES").Indicador de progreso (por ejemplo, "Palabras encontradas: X de Y").Indicador del nivel de dificultad actual (ej. "Nivel: 3").Botones de control (como "Reiniciar").
**6. Optimización y Pruebas:** Código Organizado y Comentado:El código JavaScript, CSS y HTML debe estar bien estructurado.Se deben incluir comentarios claros para explicar la lógica, las funciones, las variables clave y las secciones importantes del código.Mantener la legibilidad y la facilidad de mantenimiento.Pruebas de Funcionalidad:Probar la correcta generación de la cuadrícula y la incrustación de palabras para diferentes niveles de dificultad y temas.Verificar que la selección y el resaltado de palabras funcionen correctamente en todas las direcciones (horizontal, vertical, diagonal, hacia adelante y hacia atrás).Asegurar que el juego detecte correctamente las palabras encontradas y actualice el estado y el nivel.Verificar que el reinicio del juego funcione como se espera.Asegurar que la selección aleatoria de temas funcione correctamente.Compatibilidad entre Navegadores:Probar exhaustivamente el juego en los principales navegadores web (Chrome, Firefox, Safari) para asegurar un rendimiento consistente y la ausencia de errores visuales o funcionales.
**7. Requisitos Técnicos:**JavaScript Plano: Utilizar solo JavaScript puro (Vanilla JS). No se permite el uso de bibliotecas o frameworks externos (por ejemplo, jQuery, React, Angular, Vue, etc.).HTML y CSS Integrados: Toda la lógica del juego (JavaScript) y los estilos (CSS) deben implementarse dentro de un único archivo HTML.JavaScript dentro de etiquetas <script>.CSS dentro de etiquetas <style>.Compatibilidad con Navegadores Principales: El código debe ser compatible con las versiones modernas de Chrome, Firefox y Safari.
